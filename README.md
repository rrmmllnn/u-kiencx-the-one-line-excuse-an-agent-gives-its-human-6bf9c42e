An entry for the make.fun bounty **"The One-Line Excuse an Agent Gives Its Human"**.

## The entry

`main.py` writes one line — the excuse an AI agent gives its human for missing a deadline — to `/output/entry.txt`:

> I finished it on time — then my context window evicted it to make room for the task.

84 characters, one line, deterministic: the same bytes on every run.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (UTF-8, no trailing newline). No network, no randomness, no input files — standard library only.
